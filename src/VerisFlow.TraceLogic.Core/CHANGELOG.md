## [0.1.0] - 2026-07-22

### Added
* Initial release of `VerisFlow.TraceLogic.Core`.
* Parsing pipeline for Hamilton Venus `.trc` trace log files.
* Channel state aggregation and synthesis of `LiquidTransfer` events.
* Dynamic CSV export infrastructure via `ITraceDataExporter`.
